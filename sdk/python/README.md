# steward-sdk (Python)

Agent SDK for Steward. Specified by
[doc 11 — Agent SDK and MCP server](../../docs/20-contracts/11-agent-sdk-and-mcp-server.md):
the core workflow is §2.1, error mapping §4, packaging §11.

Python ≥ 3.10. Required dependency: `httpx`. Extras: `postgres` / `psycopg`
(`psycopg[binary]`), `sqlalchemy`, `otel`.
